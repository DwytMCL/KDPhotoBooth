# Approved product

Private online photo booth for two people apart. Main shared stage, quiet audio controls, local cutouts, common backgrounds, curated pose reference, coordinated countdown, local-resolution captures, keep/retake, gallery, four-photo strip and export. Desktop and mobile layouts.

Approved extras: pose roulette; alternating director; synchronized effects; print finishes; collaborative decoration (stickers, captions, drawing, shared positioning).

MVP: link admission, exactly two seats, reconnect, local segmentation, side-by-side/overlap placement with personal controls, studio backgrounds, category/favorite reference browsing, capture handshake, peer image transfer, shared review, two strip borders, image downloads.

Deferred core: short join codes, uploaded references/backgrounds, seasonal background collections, complex overlapping limbs, 2x2 prints, transparent exports, optional reference inclusion. Other suggested extras are unapproved.

Privacy: no media persistence or media upload to application server; original live camera video reaches partner and is segmented locally on receiving device; stills are segmented before peer transfer. Explain this before enabling camera. Local in-memory gallery disappears on reload; user saves explicitly.

Acceptance: two independent browsers on the same room can admit/reject, connect, change scenes with director authorization, ready/capture, receive the same image, retake/keep four shots, alternate director, decorate collaboratively, export a strip, and leave. Unauthorized users cannot signal, edit or capture. Hidden page/disconnect cancels readiness/capture. Desktop simulated tests do not establish actual iPhone or cross-network support.
